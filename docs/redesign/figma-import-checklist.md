# Figma Import Checklist

1. Create a new file named `LookSharp.co Redesign Review`.
2. Create two top-level pages:
- `Desktop 1440`
- `Mobile 390`
3. Add local text style family using Sora:
- H1, H2, H3, Body, Small, Kicker.
4. Add color styles from `looksharp-design-tokens.json`.
5. Add effect styles for `sm`, `md`, `lg` shadows.
6. Build reusable components first:
- Header
- CTA button (web, iOS, android variants)
- Category card
- Offer card
- Proof card
- Assurance card
- Testimonial card
- FAQ row (collapsed/expanded)
- Footer
- Consent banner
7. Assemble desktop page sections in this order:
- Header
- Hero
- Category rail
- How it works
- Offer wall
- Trust and proof
- FAQ
- Final CTA
- Footer
8. Assemble mobile page with same order and mobile constraints.
9. Add interaction notes for:
- Sticky header behavior
- Mobile menu open state
- FAQ expand/collapse
- Offer-card hover (desktop)
10. Add review labels where content is placeholder:
- featured offers
- trust metrics
- testimonials
11. Export two share images for stakeholder review:
- Desktop full-page
- Mobile full-page
