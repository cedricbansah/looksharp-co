LookSharp Landing Page — Full Implementation Prompt
PROJECT OVERVIEW
Build a single-page marketing site for LookSharp (by Insightis Africa) — a mobile rewards app where users discover discounts, complete surveys, earn points, and convert to cash. Stack: React 18 + Vite + TypeScript + Tailwind CSS + shadcn/ui + Framer Motion + React Router DOM.

5. KEY WIRING DETAILS
All colors referenced via Tailwind semantic classes (bg-primary, text-muted-foreground, etc.) — never raw values in components
Framer Motion pattern: each section wraps content in motion.div with initial={{ opacity: 0, y: 30 }}, whileInView={{ opacity: 1, y: 0 }}, viewport={{ once: true }}
Smooth scroll: html { scroll-behavior: smooth } in base styles, nav links use href="#section-id"
Header scroll detection: useEffect with scroll listener, useState boolean toggles class
Mobile menu: useState toggle + AnimatePresence for mount/unmount animation
FAQ: shadcn Accordion, no custom state management needed
Cookie consent: localStorage for persistence, custom DOM event for re-triggering from footer
shadcn/ui components used: Button, Accordion, Card — all auto-themed via CSS variables
Dependencies: framer-motion, lucide-react, react-router-dom, @radix-ui/* (via shadcn), @tanstack/react-query
Generated hero image: dark abstract teal background, saved to src/assets/hero-bg.jpg, imported as ES6 module
