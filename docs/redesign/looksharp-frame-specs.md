# LookSharp Frame Specs (Figma)

## Desktop Frame
- Width: `1440`
- Height: `Auto (content-driven)`
- Outer margins: `80`
- Content container: `1240 max`
- Section gap: `24`
- Grid suggestion: `12 columns`, `24 gutter`, `80 margins`

## Mobile Frame
- Width: `390`
- Height: `Auto (content-driven)`
- Outer margins: `10`
- Section gap: `14`
- CTA group: `2 columns` with Android button spanning both columns.

## Header
- Sticky with pill shell.
- Desktop: logo / nav / CTA.
- Mobile: logo + menu trigger.

## Hero
- Desktop: 2-column split.
  - Left: copy and CTAs.
  - Right: stat cards + visual stack.
- Mobile: stacked order copy -> stats -> visual.

## Category Rail
- Desktop/tablet: card track with 6 cards visible across wrap/scroll context.
- Mobile: horizontal scroll lane with ~170-180px card widths.

## Offer Wall
- Desktop: 3 columns.
- Tablet: 2 columns.
- Mobile: 1 column.

## Trust Section
- Proof stats: 3 -> 2 -> 1 across desktop/tablet/mobile.
- Assurance cards: 3 -> 2 -> 1 across desktop/tablet/mobile.
- Testimonials: 2 -> 1 on smaller breakpoints.

## Footer / Legal / Consent
- Footer uses dark surface and link row.
- Legal pages use centered constrained container (~860 max desktop).
- Consent banner: bottom-right desktop, full-width inset on mobile.
